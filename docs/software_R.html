Software R e IDE Rstudio

Importante📌 Lembrete importante

Para a utilização dos códigos apresentados neste minicurso, é necessário instalar o software R e a IDE RStudio. É fundamental seguir a ordem correta:

  • 1º instale o software R
  • 2º instale a IDE RStudio
  • 3º instale o Sistema Quarto

Não esqueça, é muito importante seguir essa ordem para garantir o funcionamento adequado do ambiente de desenvolvimento.

1 Definições

1.1 O que é o SOFTWARE R?

R é uma linguagem e ambiente para computação estatística e gráficos. É um projeto GNU que é similar à linguagem e ambiente S que foi desenvolvido na Bell Laboratories (antigamente AT&T, agora Lucent Technologies) por John Chambers e colegas. R pode ser considerado como uma implementação diferente de S. Existem algumas diferenças importantes, mas muito código escrito para S roda inalterado sob R (R Core Team 2025).

DicaVerificar a versão do R

Para conferir a versão do R instalada no seu computador e citar, utilize o comando:

version
citation()

1.2 O que é a IDE RSTUDIO?

O RStudio é um ambiente de desenvolvimento integrado (IDE) para diferentes linguagens de programação, incluindo R, Python e entre outras. Ele inclui um console, um editor de realce de sintaxe que suporta execução direta de código e ferramentas para plotagem, histórico, depuração e gerenciamento de espaço de trabalho. O RStudio está disponível em edições comerciais e de código aberto e roda no desktop (Windows, Mac e Linux) (Equipe RStudio 2020).

DicaVerificar a versão do RStudio

Para verificar a versão do RStudio instalada e citar, execute:

RStudio.Version()
